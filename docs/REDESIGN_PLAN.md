# Zysmy’s Lab 重构设计方案

2026-11-22 · Phase 0 · 待站主视觉验收

## 现有项目

| 领域 | 实测与代码依据 |
| --- | --- |
| 构建 | `package.json` 使用 Astro ^4.16、Vite、TypeScript、Tailwind 3。Astro 静态生成，现有分层足够支撑重构。基线 `npm run build` 成功，生成 40 个 HTML 页面。 |
| 发布 | `.github/workflows/deploy.yml` 在 main 推送或手动触发，Node 20、`npm ci`、`npm run build`、Wrangler 上传 dist。Cloudflare 凭据来自 Actions secrets。`wrangler.toml` 声明 Pages 输出目录。 |
| 页面 | `src/pages` 文件式路由。首页为文章列表并有侧栏，分类、正文、资源、相册、留言、关于、搜索均有独立页面。构建生成 21 篇正文、11 个分类或标签入口和两个专辑详情。 |
| UI | `Layout.astro` 统一外壳，可选边栏和 Banner slot。Header、Footer、Sidebar、PostCard、TagBadge、TOC、Pagination、ThemeToggle 等组件已拆分。Tailwind 工具类、页面样式和 `global.css` 共同管理样式。 |
| 内容 | `src/content/config.ts` 用 Zod 定义 Astro Content Collection，文章存于 `src/content/posts`，Obsidian 同步见现有文档。 `utils/posts.ts` 管理草稿剔除、排序、分类、标签和相关文章。正文经 Astro Markdown 和 Shiki 静态渲染。CSDN 迁移脚本留存。 |
| 交互与数据 | Fuse.js 搜索、PhotoSwipe 相册、主题切换、Giscus 留言及文章讨论、Umami 统计。个人资料散落于 about、侧栏和 consts。资源列表内联于 resources。相册 JSON 构建前从 public/images/album 扫描生成。 |
| SEO | 布局有标题、描述、OG 元数据。sitemap 生成成功。Astro site 为 pages.dev，SITE.url 为 zysmy-lab.com，canonicalURL 已进 schema，布局尚无 canonical 输出。RSS 依赖已安装，基线无 RSS 路由。 |
| 资产 | public 有 favicon、背景、日常及城市相册。图片共约 27 MB，含 4 个 HEIC，生成流程按支持格式筛选。未发现可直接用于五个 App 的独立图标或截图集，也未找到可信个人头像。 |

现有拆分可复用。主要债务按影响排序：

1. 搜索页面索引只有标题、摘要、标签，内联脚本中的 JSON 模板位于普通处理脚本，须验证运行时解析并替换为静态索引。结果拼接 HTML，改用安全 DOM 渲染。分类读取最多 100 篇，分页组件生成的 /page/N 没有对应路由。
2. 已有 Markdown 包含 `/Users/…` 本机图片路径及外链，发布构建成功无法证明媒体可用。先盘点出处与许可，找不到原图时给出文本说明。相册原图分离缩略图，原有公开路径保留。
3. 为域名、主题和个人资料建立唯一配置源。保留 Giscus pathname 及现有中文文章 slug。迁移前在预览环境验证讨论映射、统计范围和站点地图。
4. 相册查看器已接入，需验证真实尺寸、相邻图浏览与键盘焦点。系统主题、首次渲染和组件存储逻辑需要集中处理。

## 参考站与现站对照

通过 Tabbit 访问参考站首页、文章列表、文章正文、随笔、相册、留言及友链，均返回 HTTP 200。现站 /about/ 亦返回 200。桌面视口宽 1904 CSS px，移动首页宽 390 CSS px，移动记录使用桌面浏览器窄视口。

| 观察项 | 参考站 | 现站与拟采用的方向 |
| --- | --- | --- |
| 外壳 | 深色桌面顶栏横排导航，移动收起为菜单，搜索常驻。底部用独立色面、分组链接和图标形成第二层导航。 | 现站有品牌、导航和主题入口。新外壳用细边框顶栏和三组页脚，文章及实验常驻入口。 |
| 排版与留白 | 大号粗体无衬线英文起首，小号字距标签、淡色说明。宽幅城市照片连接到更窄的中置卡片区，与主体之间留出较多空间。 | 现站关于页首屏有明显大面积留白。新版将照片缩至相册和资料局部，首屏同时呈现简介和首个可用内容。 |
| 网格 | 地图宽面、人格与 App 小面、问答纵向长面。底部相册与随笔比例不同。细边框、中等圆角、深灰和暗蓝层次；移动主要单列。 | 首页从文章列表升级为 12 列工作台。以实验和文章建立主次，保留不同模块的天然比例。 |
| 内容 | App 图标与说明同组；对象生命周期模块在公开 DOM 中有按钮、代码和相关文章，但首页截图中该模块未呈现。相册有堆叠预览及箭头，随笔以引文引向按年归档。 | 使用自有文章、技术动手实验和相册素材。以真实项目资料驱动作品卡，随笔先按可发布内容呈现。 |
| 子页 | 文章页按年份聚合并提供系列，随笔按年分组，相册按专辑，留言呈现留言区与最近留言，友链有分组。 | 已有文章、相册、Giscus 可复用。独立实验和项目入口补齐，资源保留并移至页脚。 |

文章列表与正文、留言和友链首屏使用各自的封面图，随笔与相册沿用深色星点底。点击浅色切换后，截图中页脚变为浅底，首页主视觉与工作台仍为深底。本次只验证了首页的局部变化。参考首页地图截图仍为加载态。参考站页面切换动画、hover 全套细节、触屏真机行为、登录后的问答及提交行为未经完整验证。视觉取样仅用于设计研究。

## 首页布局草图

桌面 ≥ 1120px，主容器 1200px，12 列，间隙 20px。行高由内容决定。左侧实验跨两行，右侧文章与状态独立收口。

```text
│ Profile · Zysmy                           │ 个人信息 / 可用状态     │
├────────────────── 8 ────────────────────┼────────── 4 ──────────┤
│ iOS Lab                                   │ 最新文章（3 条）        │

│                                           │ GitHub 活动            │
├─────────────── 6 ─────────────┬───────────┴──────── 6 ───────────┤
│ App 作品展厅                   │ 相册预览                         │
├───────────────────────────────┼──────────────────────────────────┤
│ 随笔                           │ iOS 知识库                       │
└───────────────────────────────┴──────────────────────────────────┘
探索内容                         站主与联系                        社交
```

```text
390 px
品牌                 搜索 主题 菜单
[头像、英文标题、简介、GitHub]
[个人信息 / 已确认状态]
[iOS Lab：切换 → 图 → 按钮 → 代码]
[最新文章]
```

平板采用 8 列，Profile 与 Lab 通栏，其余按可读宽度 4+4 或通栏。移动保持 DOM 阅读顺序。对应阶段尚未交付的模块可整块延后，避免无内容的空网格。

## 模块 UI

| 模块 | 内容与操作 | 空、缺失或失败 |
| --- | --- | --- |
| Profile | 56–72px 头像位、拟定英文标题 “Exploring iOS, from the inside out.”，现有关于页简介、iOS / Runtime / 内存 / 多线程方向，GitHub 与关于入口。 | 用文本 Z 字标。真实头像入库后替换。 |
| Personal | 使用定义列表和紧凑标签。地点旁用等宽数字展示分钟级时间，状态和在做项目可链接详情。 | 地点、时区、当前状态和项目待确认，空字段省略。作者时钟仅在作者时区确认后展示。 |
| Apps | 48px 图标选择器，名称与选中态，可键盘切换。下方显示摘要、类型、真实截图或开发笔记入口。项目详情从图标、摘要、截图进入核心功能、技术栈、架构、技术亮点、GitHub 和开发日志。 | 3G-Share、Weather 有总结可引用，3G-Share 的本机截图引用需回收原件。Spotify、网易云音乐、Calculator 待提供证据。统一文字标识和「资料待补充」，已确认条目开放详情。 |
| iOS Lab | 实验名、下拉或上一个/下一个、简短任务、图解、操作、可折叠代码、状态提示、原理及相关文章。独立页可展开日志，列表按对象模型、并发、框架机制分组。 | 禁用当前无效动作并给出状态说明；关闭自动轮播；交互加载失败显示初始图解及正文链接。 |
| Articles | 最新三条显示标题、分类、更新时间（缺失时显示发布日期）、估算阅读时间。列表横排筛选、搜索及系列入口；归档按年；详情窄正文、桌面侧目录、手机折叠目录、代码复制、阅读进度、上下篇与实验嵌入。 | 筛选无结果有清除入口，正文图片失败显示替代说明。 |
| Thoughts | 首页单条真实摘录与日期，详情用日期及细线组成编辑式时间轴，长文可展开详情。 | 无随笔时隐藏首页摘录，栏目显示简短空态。 |
| Gallery | 首页 4:3 真实照片及相册入口，横向拖动与按钮并存；相册页专辑封面与 1–4 列缩略图。全屏有计数、关闭、前后键和触摸滑动。 | 图片失败保留尺寸及替代文本，缩略图链接可直接打开原图。 |
| GitHub | 近 90 日公开事件热力图与更新时间、图例、GitHub 入口，附最近公开动态文本。 | 暂无快照、快照过期和成功但零活动分别处理。 |
| Knowledge Base | 简短介绍、筹备状态及 Runtime、内存管理、并发阅读入口，输入区布局留待评估。 | 暂以真实文章链接提供可用路径。 |
| Guestbook / Links | 留言页短引导及 Giscus；友链用分类列表、站点描述、外链和申请入口。 | Giscus 超时给可用讨论入口；友链先入库审核，无名单时展示申请说明。 |
| About / Resources | 关于页保留作者自述、时间轴和联系方式，资源按书籍、工具和技术资料分组。 | 标明失效或待核实链接，从默认列表收起。 |
