# Zysmy’s Lab Design System

Phase 0 设计规格。主题采用中性纸白、深石墨与单一钴蓝强调色。相册保留真实色彩，代码和实验允许按状态加色。卡片仅用在独立交互和媒体模块，文章与随笔用留白和分隔线建立层级。

## 色彩

变量集中到 `styles/tokens.css`。Tailwind 通过语义名引用，正文和组件只消费语义变量。主题通过 HTML 的 `data-theme` 设置，迁移期间与现有 Tailwind dark class 同步。

## 排版、间距、形状

| 层级 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 首页标题 | 34–54px / 1.08 | 700，英文轻微收紧 |
| 页面标题 | 30–42px / 1.15 | 700 |
| 区块标题 | 21–26px / 1.25 | 650–700 |
| 卡内标题 | 17–20px / 1.35 | 600 |
| UI 正文 | 15–16px / 1.6 | 400 |
| 文章正文 | 17–18px / 1.8 | 400 |
| 元信息 | 13–14px / 1.5 | 400–500 |
| 代码 | 13–15px / 1.65 | 400 |

UI 用系统无衬线、PingFang SC、Microsoft YaHei 回退。代码用 SF Mono、Menlo、Consolas。正文宽 720px 上限，行长依中英文样稿检验。段距 16px，二级标题前留 36px。代码块和宽表格各自横向滚动。

- 间距 token 为 4、8、12、16、20、24、32、40、48、64px。模块内默认 20–24px，行内组 8–12px，区块上下 40–64px。
- 圆角 token 为 8px 控件、12px 媒体和 App icon、18px 卡片、24px 焦点模块、999px 标签。卡片为 1px 描边。
- 阴影仅三档。none 为常态，raised 为 `0 8px 24px #10142012`，overlay 为 `0 20px 64px #10142033`，深色 alpha 调至约 0.32 和 0.65。
- 图标 18–20px，工具按钮和移动端操作目标至少 44×44px。文本链接带下划线或充分明确的上下文，图标按钮有可访问名称。

## 响应式

| 宽度 | 网格及留白 | 导航 |
| --- | --- | --- |
| 320–767px | 1 列，边距 16px，gap 12–16px | 56px 顶栏，品牌、搜索、主题、菜单 |
| 768–1119px | 8 列，边距 24px，gap 16px | 64px 顶栏，折叠菜单 |
| ≥1120px | 12 列，边距至少 32px，gap 20px，内容最大 1200px | 横排八栏，两个工具按钮 |
| ≥1440px | 固定主内容最大宽度，居中 | 内外容器对齐 |

文章详情仅在足够宽时使用侧目录，移动端代码、表格和项目图廊控制局部溢出。正文图片预留宽高，装饰图裁切以局部容器为边界。字号放大到 200% 时控件允许换行，菜单仍可达。

## 主题与交互

- Light / Dark / System 三态。首次绘制前应用合法存储值或系统主题。系统模式才监听媒体查询，存储受限时保留当前会话选择。同步 Giscus 与 `color-scheme`。
- 动画 token 120ms 控件、180ms 卡片、240ms 弹层和可用时的页面过渡，统一 `cubic-bezier(.2,.7,.2,1)`。Hover 只给可交互元素，移动最多 2px，边线变化提供选中反馈。输入焦点始终可见。
- prefers-reduced-motion 取消位移、平滑滚动、页面淡入与实验图形补间。实验状态仍即时更新。浏览器不支持页面过渡时使用原生导航。
- 菜单、搜索和灯箱具备 Esc、焦点管理和关闭后归位。搜索按钮展示快捷键，移动保留显式入口，输入法组成期间避免拦截快捷操作。
- 返回顶部在长页滚动后出现，激活后焦点回主内容起点。静态页面直接显示内容；异步功能用等高占位及可感知加载提示，失败带可恢复入口。空态说明原因及下一项可用操作。
- 页脚采用分组链接，手机两列或单列，保留版权、联系方式及站点地图。阅读页使用薄分隔，首页页脚可使用轻微色面。
